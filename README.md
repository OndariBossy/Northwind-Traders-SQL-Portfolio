
## Northwind Traders | SQL Sales Performance Analysis

## Project Overview

This project analyzes the Northwind Traders dataset using SQL to uncover insights into sales performance, customer purchasing behavior, product performance, and shipping operations.

## Tools & Skills

SQLite and DB Browser for SQLite

SQL joins, aggregations, subqueries, and Common Table Expressions (CTEs)

Data analysis and business reporting

## Business Questions

What is the average order value?

Which months generate the highest sales revenue?

Who are the highest-value customers?

Which products perform best and worst?

How do shipping providers compare?

## Key Findings

Average order value: 1,525.05

Highest-revenue month: April 2015, generating 123,798.68

Top customer: QUICK-Stop, generating 110,277.30

Most-ordered product by quantity: Camembert Pierrot, with 1,577 units

Highest average shipping cost: United Package, at 86.64 per order

## Business Recommendations

Strengthen relationships with high-value customers.

Investigate seasonal sales patterns to improve planning.

Review underperforming products and potential promotional opportunities.

Compare shipping providers to identify cost-efficiency opportunities.
